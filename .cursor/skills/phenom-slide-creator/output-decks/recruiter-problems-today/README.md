# Current Problems Recruiters Face Today

## Files
- `Current-Problems-Recruiters-Face.pptx` — Phenom-branded 10-slide deck (upload to Google Drive → Open with Google Slides)
- `index.html` — browser preview (same layouts)

## Import to Google Slides
1. Open [Google Drive](https://drive.google.com)
2. Upload `Current-Problems-Recruiters-Face.pptx`
3. Right-click → Open with → Google Slides
4. File → Save as Google Slides (optional, for full editability)

Or: In an existing Slides deck → File → Import slides → select the uploaded file.
