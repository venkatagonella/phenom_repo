# CRM Themes → Jira Gap Map

Phenom HTML deck (reveal.js + Poppins) mapping every Jan–Aug 2026 SR theme across
the four CRM areas to open Initiative / Epic / Story coverage on board 1091.

**Open:** [`template.html`](./template.html)

## How to read

| Column | Meaning |
|--------|---------|
| SR theme | Classified service-request theme + case volume |
| Open Jira coverage | Counts of open Initiatives, Epics, Stories. A missing level is **TBD**. Rows with no open match at any level are highlighted and say **TBD — Needs new Initiative, Epic, and Story**. |
